# Pip's Mushroom Island — 3D pass

The V2 visual pass is a deliberate move toward the richly detailed miniature illustration previously shown as an inspiration image. **That earlier image was NOT an actual build screenshot.** This release must be judged by CI-captured WebGL screenshots, not by inspiration imagery. V2 adds a softly textured grass surface, natural-looking layered shoreline strata and coastal ripples, coordinated mushroom frontages and warm windows, more substantial castle roof/window/steps, small connecting paths, grounded grove canopies, and a fuller yet calm waterfall. Pip is larger and grounded more convincingly. Landmark taps now provide actual closer camera focus. It is still procedural miniature art, not a pixel-perfect replica of a separately produced reference. The real WebGL island is a separate renderer in `assets/mushroom-island-3d.mjs`. It models an island/cliff, castle, mushroom village, wooden bridge, waterfall, small woodland and flower beds, and a 3D Pip (teal leaf cap, purple coat, scarf, satchel, boots). Pip animates along a visible walking circuit. Orbit via drag, zoom via wheel or pinch, tap landmarks to learn more.

The original `mushroom-cinematic.js` and `mushroom-life.js` remain untouched; they are available through the single 2D toggle and automatically used if Three.js/WebGL cannot start. Parent `mushroom:motion` events, visibility and reduced-motion settings are handled. Portrait starts at island-wide zoom. Pip Run's independent platformer engine is untouched.

Tests: `node tests/mushroom-island-3d.test.cjs` and Playwright Chromium `node tests/mushroom-island-3d-visual.cjs`. Screenshots save as `visual-artifacts/pip-island-*.png` (desktop overview, castle, village, bridge, waterfall, Pip, phone overview and phone village). To see what really shipped, open the **Mushroom Island 3D checks** GitHub Actions run, then its `pip-island-3d-preview` artifact. Do not show generic generated imagery as the deployed visual. Physical Safari/iPhone quality not independently verified. Preserve the clean original 2D fallback on future edits.
