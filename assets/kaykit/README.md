# KayKit models (CC0)

`kaykit-town.glb` merges the models Toy Town uses from two free packs by **Kay Lousberg** (www.kaylousberg.com), both released under **CC0 1.0** (public domain; credit not required, given gladly):

- *KayKit City Builder Bits 1.0*: buildings A–H (without base), five cars, streetlight, traffic light, bench, fire hydrant, bins, dumpster, box, bush, water tower.
- *KayKit Medieval Hexagon Pack 1.0*: trees (single A/B, clusters A/B), clouds (big/small), barrel, crate.

Each model sits under a root node named after it (e.g. `building_C`, `car_taxi`, `tree_single_A`). Built with glTF-Transform (merge, dedup, weld, prune) from the packs' `.gltf` sources.
