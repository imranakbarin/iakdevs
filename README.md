# Infinite World Scrolls

A standalone canvas experience at https://imranakbarin.github.io/iakdevs/.

World art retains the original Gond, Warli, Madhubani and Kangra landscapes and adds original interpretations inspired by Japanese woodblock prints, Chinese ink landscapes and Mexican folk art.

Road trip is an illustrated four-lane touring drive with curved roads, a detailed foreground car, oncoming vehicles, same-direction traffic and automatic overtaking. Traffic can be toggled off. Landscape palettes blend between mountain, desert, forest, coastal and city segments every 32 journey seconds. Weather cycles through sun, sunset, rain, fog, snow and night every 27 journey seconds. Manual place and weather selectors hold a state. The drive is an animation, not a traffic physics simulator. Pause and speed apply to both modes; New landscape resets the journey. Reduced-motion preferences pause autoplay.

Run locally with `python3 -m http.server 4174 --bind 0.0.0.0`. No build or package installation is needed. GitHub Pages publishes master.
